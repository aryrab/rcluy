RCL CUEROS — logo en todas las vistas previas y enlaces directos de producto

Objetivos de esta versión:
- Cualquier enlace compartido muestra https://rcluy.vercel.app/logocompleto.png como imagen de vista previa.
- Los enlaces de producto mantienen el formato https://rcluy.vercel.app/?producto=ID.
- Al abrir un enlace de producto, el catálogo busca el ID en todas las categorías y vuelve a intentar la carga si alguna falla.
- La navegación Atrás/Adelante mantiene el estado del producto y la URL directa para que una recarga no pierda el ID.

Archivos:
- index.html: reemplaza el index.html del proyecto.
- vercel.json: enruta los bots de vistas previas a /api/share.
- api/share.js: devuelve metadatos de vista previa con el logo para inicio y productos.

Instalación:
1. Copiá index.html a la raíz del proyecto.
2. Copiá api/share.js dentro de una carpeta api en la raíz.
3. Integrá vercel.json con la configuración existente. Si tu proyecto ya tiene vercel.json, no lo sobrescribas sin revisar las reglas actuales.
4. Confirmá que logocompleto.png esté en la raíz y accesible en https://rcluy.vercel.app/logocompleto.png.
5. Hacé deploy en Vercel.
6. Probá en el navegador https://rcluy.vercel.app/?producto=33 y otro ID real. Debe abrir directamente la ficha; recargar la página debe mantenerla abierta.
7. Para WhatsApp, tené presente que las vistas previas pueden quedar en caché un tiempo.

Nota: no se pudo probar el deploy real desde este paquete. La regla de vercel.json está incluida como configuración sugerida y debe integrarse con la existente si la hubiera.
